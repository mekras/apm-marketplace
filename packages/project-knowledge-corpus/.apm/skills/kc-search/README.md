# Поиск по корпусу знаний

Попросите агента найти основание обычным вопросом:

```text
Найди в корпусе, что сказано о сопровождении стажёров. Проверь утверждения,
стенограммы и другие подходящие материалы. Дай цитаты и точные ссылки.
```

Агент проверит, какие материалы ему разрешено читать, выполнит поиск и прочитает
подходящие фрагменты. Ответ покажет источники и ограничения. Если материал не найден,
будет понятно, где агент искал и что осталось недоступным.

Можно искать по словам или подключить поиск по смыслу:

- **По словам.** Например, слово «наставника» найдёт фразу «Стажёру назначают
  наставника». Для этого не нужно скачивать дополнительную модель ИИ.
- **По смыслу.** Вопрос «Будет ли у новичка помощник?» может привести к той же
  фразе, хотя слова в вопросе и материале различаются.

Для поиска по смыслу нужна дополнительная модель ИИ, которая сравнивает смысл
вопроса и текстов. Для E5 есть [инструкция подключения](references/e5-setup.md).
При первом подключении модель нужно скачать и настроить, после чего она будет работать
на вашем компьютере. Писать программу для её подключения не требуется.
По умолчанию модель и необходимые программы устанавливаются в общую папку
пользователя. Следующий проект использует ту же совместимую установку.
У каждого проекта остаются свои настройки и материалы для поиска.
Можно использовать и другую модель, но для неё понадобится отдельная настройка
по [техническому описанию подключения](references/embedding-contract.md).

После настройки попросите агента:

```text
Найди в корпусе ответ на вопрос «Будет ли у новичка помощник?».
Используй поиск по смыслу и покажи найденные цитаты с точными ссылками.
```

Оба способа поиска можно объединить. Какой из них полезнее, проверяют
на вопросах вашего проекта. [Пример сравнения](evals/semantic-benchmark.md)
показывает результаты на небольшом искусственном наборе материалов.

Найденный фрагмент ещё нужно прочитать и проверить: похожий текст может
не отвечать на вопрос. Если нужного материала нет среди результатов,
это не доказывает его отсутствия во всём корпусе.

[Требования к программам и команды запуска](SKILL.md) предназначены для
самостоятельной настройки. [Техническое описание поиска](references/search-contract.md)
задаёт состав проверяемых материалов и формат результатов.
