# Подключение локального E5

Этот профиль позволяет запустить смысловой поиск без написания своего адаптера.
Он использует `Xenova/multilingual-e5-small`, ONNX INT8, на CPU. Исходная модель —
[`intfloat/multilingual-e5-small`](https://huggingface.co/intfloat/multilingual-e5-small),
лицензия MIT. Версия конвертации закреплена:
[`761b726dd34fb83930e26aab4e9ac3899aa1fa78`](https://huggingface.co/Xenova/multilingual-e5-small/tree/761b726dd34fb83930e26aab4e9ac3899aa1fa78).
Веса и токенизатор проверяются по хэшам из поставляемого модуля профиля перед
каждым вычислением. Профиль возвращает 384 числа на текст.

Проверенная среда: Linux x86-64 и CPython 3.13. Видеокарта не требуется.
Установка профиля необязательна. Для другой платформы сначала проверь наличие
совместимых бинарных пакетов и выполни контрольный поиск. При отсутствии среды
продолжи основной маршрут чтения файлов из `SKILL.md`.

## Подготовка

Агент находит установленный каталог `kc-search`, Python 3.13 с модулем `venv`
и pip с поддержкой `--python`. Проверяет разрешение на установку программ,
загрузку модели, запись в общую папку пользователя и обработку выбранных
материалов отдельным локальным процессом.

По умолчанию модель и программы для её запуска размещаются в общей папке
пользователя. Несколько проектов используют одну и ту же совместимую установку.
В проекте остаются только описание материалов для поиска и настройка подключения.
В общей папке тексты корпуса и результаты поиска не сохраняются.

В Linux общая папка — `$XDG_CACHE_HOME/project-knowledge-corpus`, если
`XDG_CACHE_HOME` задан абсолютным путём. Иначе используется
`~/.cache/project-knowledge-corpus`. Файлы модели лежат в `models/` с именем
и версией модели, среда запуска — в `runtimes/` с версией Python, платформой
и хэшем набора зависимостей. Поэтому новая версия не заменяет файлы,
которые ещё нужны другим проектам.

Не включай общую папку в материалы для поиска и не помещай её внутри навыка.
Если политика проекта запрещает запись в общую папку, выбери разрешённое место
явно. Отдельная установка должна быть осознанным исключением.

## Создание настройки

Подготовь `search-scope.local.json` по договору корпуса. Проверь конкретные
источники и ограничения передачи текстов адаптеру, затем получи SHA-256 файла.
Например, через `sha256sum search-scope.local.json`. Подставь полученный хэш
вместо `ПРОВЕРЕННЫЙ_SHA256`:

```sh
kc_skill_dir=".agents/skills/kc-search"
PYTHONDONTWRITEBYTECODE=1 python3.13 "$kc_skill_dir/scripts/configure-e5.py" \
  --scope search-scope.local.json \
  --approved-scope-sha256 ПРОВЕРЕННЫЙ_SHA256 \
  --output embedding.local.json \
  --prepare-runtime \
  --download-model
```

Пример рассчитан на POSIX-оболочку и установленный навык Codex. Для Claude
найди его в `.claude/skills/`. Команда показывает выбранные пути в результате.

Флаг `--prepare-runtime` разрешает подготовить общую среду и установить пакеты
из `e5-requirements.txt` с проверкой версий и SHA-256. Уже подготовленная
совместимая среда используется повторно без установки. Флаг `--download-model`
разрешает загрузить два закреплённых файла по HTTPS с Hugging Face. Проверенные
локальные файлы используются без повторной загрузки. Существующие файлы
с другим хэшем и существующая настройка проекта не перезаписываются.

При настройке следующего проекта повтори команду с его областью и выходным
файлом. Если пользователь, версия Python и версия навыка совместимы,
будут выбраны те же файлы модели и та же среда запуска. Скачивать модель
или устанавливать программы для каждого проекта заново не потребуется.

Одновременная подготовка одной среды останавливает второй запуск с просьбой
повторить его позже. Не удаляй блокировку работающей подготовки.
При обычном отказе новая незавершённая среда удаляется. После аварийного
завершения проверь, что процесс остановлен, прежде чем удалять оставшуюся
блокировку или незавершённую среду. Существующая установка сохраняется.
Частичная загрузка текущего файла модели удаляется, уже проверенные файлы остаются.

Без обоих флагов команда использует уже подготовленную общую среду и создаёт
только настройку проекта. При отсутствии среды она отказывает с подсказкой.
Для автономной работы заранее подготовь среду и файлы `model_quantized.onnx`
и `tokenizer.json`. Через `--model-dir` можно выбрать существующую папку модели,
через `--runtime-python` — готовую среду запуска. Последний параметр не совмещается
с `--prepare-runtime`. Параметр `--shared-dir` меняет корень общей установки,
если стандартное расположение не подходит. Эти параметры сохраняют возможность
отдельной установки, когда она нужна по правилам проекта.

Создание настройки ещё не проверяет обработку текста настоящей моделью.
Это делает следующий поиск. При ошибке конфигурации или модели исправь причину
и повтори запуск. Для новой конфигурации используй новый путь либо удали старую
после проверки. После перемещения проекта или переустановки навыка по другому
пути создай настройку заново: она содержит абсолютные пути этого проекта.

Старые настройки с явными путями продолжают работать. Для перехода на общую
установку создай новую настройку, проверь поиск и затем замени используемую
настройку проекта. Старые копии автоматически не удаляются. Перед их удалением
убедись, что на них больше не ссылаются другие настройки.

## Проверка и применение

```sh
PYTHONDONTWRITEBYTECODE=1 python3.13 "$kc_skill_dir/scripts/search-corpus.py" search \
  --corpus-root knowledge --scope search-scope.local.json \
  --mode semantic --embedding-config embedding.local.json \
  --query "Останется ли начинающий без помощи?" --top-k 3
```

Успешный поиск подтверждает совместимость команды, среды, модели и текущих
входов. Просмотри фрагменты, строки, ограничения и охват. Затем проверь качество
на вопросах своего проекта через `evaluate --mode compare`, включая точные
термины, перефразировки и вопросы без ответа. Искусственный
[пример сравнения](../evals/semantic-benchmark.md) не гарантирует тот же результат
на другом корпусе.

Вопрос и фрагменты получают префиксы E5 автоматически из настройки. При входе
свыше 512 токенов адаптер отказывает без усечения. Уменьши `max_input_chars`
в локальной настройке и повтори проверку. Векторы пересчитываются при запуске,
поэтому время работы на большом корпусе нужно измерять отдельно.

## Другие модели

E5 — готовый стартовый профиль. Для другой модели предоставь локальную команду
по [общему договору](embedding-contract.md) и настрой её версию, префиксы и лимиты.
Адаптер E5 специально проверяет свои веса и версии, подмена имени модели
в его настройке не переключает его на другую модель. Выбор другой модели
требует сравнения на одинаковых вопросах и материалах.
