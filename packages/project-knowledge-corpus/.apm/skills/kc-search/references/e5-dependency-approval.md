# Необязательные зависимости профиля E5

Пользователь поручил добавить сопровождаемый адаптер E5 и процедуру настройки
после описания работающего опыта с ONNX Runtime, tokenizers и NumPy.
Поручение «Делай» и его продолжение от 5 ноября 2026 года разрешают поставку
этого необязательного профиля. Закреплены испытанные версии NumPy 2.2.2,
ONNX Runtime 1.26.0 и tokenizers 0.22.2. Область — только вычисление векторов
локальной моделью в `scripts/e5_runtime/adapter.py`.

Общий поиск сохраняет стандартную библиотеку Python, а основной маршрут
навыка — файловые средства агента. Установка профиля в проекте-потребителе
выполняется отдельно по его правилам. Это поручение не разрешает автоматически
устанавливать зависимости во всех проектах.

Версии прямых и транзитивных зависимостей и хэши артефактов находятся в
[`e5-requirements.txt`](../assets/e5-requirements.txt). Установка с проверкой
хэшей описана в [процедуре подключения](e5-setup.md). Испытанная среда —
Linux x86-64, CPython 3.13, CPU. Другие платформы этим прогоном не проверены.

Источники и лицензии прямых зависимостей:

- [NumPy 2.2.2](https://pypi.org/project/numpy/2.2.2/), BSD-3-Clause.
- [ONNX Runtime 1.26.0](https://pypi.org/project/onnxruntime/1.26.0/), MIT.
- [tokenizers 0.22.2](https://pypi.org/project/tokenizers/0.22.2/), Apache-2.0.

Пакеты и модель загружаются только на этапе явной подготовки. При вычислении
векторов адаптер читает локальные файлы и не использует функции загрузки
Hugging Face. Отсутствующая библиотека, другая версия, изменённые веса или
превышение токенов приводят к отказу без вывода текста запроса. Сигналы среды
не являются сетевой песочницей. Изоляцию при необходимости задаёт потребитель.
