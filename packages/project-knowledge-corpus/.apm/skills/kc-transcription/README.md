# kc-transcription

Получает сырой `transcript.txt` из локального аудио или видео с проверкой
ресурсов и безопасной очисткой временного медиа после проверки результата.
Большое временное медиа можно обработать составной возобновляемой операцией
получения, расшифровки, проверки и очистки.
Договор исполнителя описан в
[references/transcription-contract.md](references/transcription-contract.md).
