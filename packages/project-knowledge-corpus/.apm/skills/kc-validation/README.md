# kc-validation

Проверка отдельно оценивает наличие и целостность снимка, происхождение,
сопоставление с первоисточником, актуальность, условия использования и текущую
локальную доступность. Проверка при получении достаточно обосновывает
неизменный снимок. Повторное получение всех источников не входит в обычную
проверку корпуса. Актуальность оценивается для конкретного применения. Локальный сбой не отменяет переносимую проверку снимка с
совпадающим хэшем.
