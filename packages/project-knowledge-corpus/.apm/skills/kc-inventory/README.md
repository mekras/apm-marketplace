# kc-inventory

Навык ведёт учёт источников, снимков и переносимых проверочных оснований.
Проверка текущего снимка хранится в необязательном `verification.yml` рядом с
единицей и связана с SHA-256 артефакта. Локальная доступность и профили доступа
остаются вне Git.

Для проверки новой схемы используйте `validate-corpus-layout.py` с
`--strict-verification`. Для ручной записи или миграции одной единицы служит
`scripts/record-snapshot-verification.py`. Старые единицы без нового файла
продолжают читаться в режиме совместимости. Для изменяемого индексируемого
источника карточка либо ссылается на зарегистрированный адаптер, либо задаёт
`adapter: agent` с `agent_route`; значение `manual` остаётся только
диагностируемым legacy-маршрутом и не считается способом получения. Дельта
индекса отделяет техническое изменение от содержательного по `change_policy`.
Правила оценки полноты набора источников, свежести, discovery/evidence-ролей и
дедупликации событий находятся в
[`references/source-quality-policy.md`](references/source-quality-policy.md):
они применяются к корпусу проекта-потребителя, а не создают корпус коллекции.
