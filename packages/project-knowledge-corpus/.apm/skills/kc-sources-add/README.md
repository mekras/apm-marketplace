# kc-sources-add

Техническое добавление нового источника в корпус знаний. Навык применяет
безопасные проектные умолчания, сохраняет неизвестные сведения явно и
эскалирует только решение, которое нельзя принять автоматически.

Карточка отделяет постоянные требования к доступу от состояния текущего
окружения. Проект может зарегистрировать собственный адаптер, а локальный
профиль и секрет остаются вне Git. Предоставленный пользователем материал
получает происхождение `user_provided` и не считается сверенным с
первоисточником.
