# kc-setup

Навык настраивает проект на использование корпуса знаний: добавляет или
обновляет раздел в `AGENTS.md`, фиксирует папку корпуса и проверяет уже
существующий корпус через навыки коллекции.

При настройке навык также проверяет, какие материалы разрешено включать в
корпус, где сохранять проектные решения и какой командой проверять допуск
источников. Рабочий разговор с агентом не становится источником автоматически.
Принятые местные правила сохраняются. Если границы не определены, навык
предлагает конкретную настройку владельцу.

Настройка готовит исполнителей операций для текущих и уже порученных
источников. Отсутствующие будущие виды источников не требуют инфраструктуры
заранее. Недостающие применимые механические команды создаются и проверяются
в том же поручении; смысловую работу выполняет агент.

Пустой корпус проходит глобальные стадии и итоговую проверку. После этого
он готов принимать источники. В новой сессии работа продолжается по
сохранённому состоянию, а при добавлении источника охват операций проверяется
заново. [Граница готовности](references/setup-readiness.md).

Пример использования:

```text
Настрой корпус знаний в этом проекте.
```
