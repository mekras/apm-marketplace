# kc-setup

Навык настраивает проект на использование корпуса знаний: добавляет или
обновляет раздел в `AGENTS.md`, фиксирует папку корпуса и проверяет уже
существующий корпус через навыки коллекции.

Навык также сам предлагает завести настройки операций и исполнителей очередей,
не дожидаясь просьбы. Механическую работу — получение материала, преобразование
формата, пересборку указателей и проверки — он предлагает передать проектной
команде или адаптеру. Смысловую работу оставляет за агентом и говорит об этом
прямо, чтобы было видно, где обработка пойдёт сама, а где потребует времени
модели.

Пример использования:

```text
Настрой корпус знаний в этом проекте.
```
