# Проверка доступности знаний

`kc-retrieval-evaluation` выборочно проверяет, может ли выбранная модель найти
через корпус важные утверждения первоисточников и правильно ответить по ним.

Навык не заменяет `kc-validation`. `kc-validation` проверяет структуру,
прослеживаемость и содержательные дефекты самого корпуса без модельного
измерения. `kc-retrieval-evaluation` запускает отдельные модельные сессии и
оценивает пользовательский путь от вопроса до ответа.

## Перед началом

Подготовьте:

- корпус с доступными первичными или нормализованными материалами;
- область проверки, например выбранные источники или пользовательские задачи;
- модель, которая будет отвечать через корпус;
- адаптер запуска модели;
- решение о том, разрешено ли выбранным моделям читать корпус и опорные
  фрагменты источников.

Заполненная настройка моделей и полученные отчёты должны оставаться в локальном
слое с маркером `.local.` вне корня корпуса. Адаптер должен изолировать каждую
модель текущим рабочим каталогом и поддерживать режим без записи.

## Первый запуск

Обратитесь к агенту обычным запросом:

```text
Проверь, сможет ли выбранная модель находить важные утверждения через этот
корпус знаний.
```

Агент уточнит область измерения, независимо выберет фрагменты
первоисточников, подготовит проверочные примеры и покажет, какой локальный
адаптер нужен для прогона.

Если набор примеров уже создан:

```text
Запусти проверку доступности знаний по набору
knowledge-evaluation.local.yml и объясни причины неудачных ответов.
```

## Что получится

Результат разделяет:

- отсутствие целевого смысла в `statements.yml`;
- отсутствие в ответе проверяемого основания, которое служит кандидатом
  проблемы поиска;
- искажение указанного основания в ответе;
- успешный ответ без корпуса, который уменьшает доказательность примера;
- дефект самого эталона или вопроса.

Оценка относится только к выбранным источникам, вопросам, модели и способу
доступа к корпусу. Она не доказывает полноту всего корпуса.

Полная процедура описана в [SKILL.md](SKILL.md). Формат набора, показатели и
классификация отказов приведены в
[протоколе проверки](references/evaluation-protocol.md).
