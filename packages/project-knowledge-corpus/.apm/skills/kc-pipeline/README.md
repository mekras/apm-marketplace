# kc-pipeline

Координирует полный проход корпуса: от учёта и получения первичных данных до
проверки влияния, безопасных правок и финальной проверки корпуса. Для проектов
с повторяемыми запусками
навык также даёт переносимый операционный контур: планирование очередей,
явный запуск проектных команд и адаптеров, автономное продолжение очереди с
сохранением состояния между сеансами, пересборку производных индексов и
локальный отчёт. Исполняемый проход включает согласование понятий, анализ
влияния, перенос безопасных изменений и финальную проверку. Перед
`completed` он повторно проверяет публикуемый слой Git. Ресурсно недоступная
очередь не блокирует другие готовые задачи, а внешние вопросы группируются по
решению с ограниченным бюджетом внимания и полным машиночитаемым хвостом.
Подробности см. в
[договоре операций](references/operations-contract.md) и
[договоре адаптеров](references/adapter-contract.md).
