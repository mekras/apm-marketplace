# Разрешение PyYAML для необязательной автоматизации

Статус: принято 2026-10-19 ответственным за решение по проекту.
Основание принятия: явное согласие пользователя проекта на PyYAML 6.0.3
и оформление этого разрешения при настройке коллекции.

PyYAML 6.0.3 разрешён только для обработки YAML в следующих файлах:

- `scripts/run-corpus-operations.py`

Зависимость уже использовалась этими файлами. Переписывание обработчика YAML
в рамках оформления разрешения не требуется. Основной результат навыка
по-прежнему можно получить вручную по разделу «Переносимость» в `../SKILL.md`.

Перед использованием автоматизации проверьте Python 3.10+ и доступность
PyYAML 6.0.3. Установка требует отдельного явного решения пользователя.
Из каталога навыка вызовите обнаруженную команду Python 3 с аргументами:

```text
-m pip install --no-deps --require-hashes -r references/pyyaml-requirements.txt
```

Файл закрепляет версию и SHA-256 всех 72 wheel-артефактов
[выпуска PyYAML 6.0.3](https://pypi.org/project/PyYAML/6.0.3/).
Артефакты скачаны без установки, их хэши сверены 2026-10-19.
Установка допускает только готовые wheels. Если подходящего wheel нет,
установка завершается отказом без сборки или загрузки зависимостей сборки.
Для загрузки нужна сеть. Сами операции навыка используют локальные файлы.
Лицензия PyYAML — MIT. При распространении копии пакета сохраняйте его
уведомления об авторстве и текст лицензии. Данная коллекция пакет не включает.

Без PyYAML зависимая операция останавливается с сообщением о пакете.
Скрипты не устанавливают его автоматически. Агент сохраняет ограничение
среды и продолжает ручной маршрут. Отказ и отсутствие изменений данных
проверяются отдельными регрессионными сценариями коллекции.

Разрешение не распространяется на другие импорты или файлы. При смене версии,
области применения, способа установки или лицензии его нужно пересмотреть.
