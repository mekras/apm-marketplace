# Идентификаторы утверждений

Используй эту справку, когда задача требует формализовать ID утверждений или
разграничить конечный и промежуточный слой.

## Идентификатор источника

Перед нумерацией зафиксируй короткий идентификатор источника:

- не более 5 символов;
- только прописные латинские буквы;
- один и тот же идентификатор во всех слоях корпуса.

## Конечные утверждения

Для конечных утверждений, на которые могут ссылаться документы проекта,
используй устойчивый формат:

- `<SOURCE-ID>-001`
- `<SOURCE-ID>-002`

Числовая часть должна быть уникальной внутри источника и не меняться без
необходимости после появления в Git.

## Промежуточные кандидаты

Для промежуточных артефактов допустим отдельный локальный формат, но он должен:

- явно отличаться от конечного ссылочного формата;
- не использоваться как постоянная ссылка в производной документации;
- быть достаточным для локальной трассировки внутри текущего артефакта.

## Что считать ошибкой

- использовать локальные короткие ID как постоянные ссылки для конечных
  утверждений;
- смешивать в одном артефакте конечные ID и временные локальные ID без явной
  причины;
- назначать ID до определения идентификатора источника.
