# Аудит правил проекта для агентов

`ai-audit-project` проверяет всю систему управления агентом в репозитории:
`AGENTS.md`, инструкции разных сред, локальные и глобальные навыки, связи с
APM и поставляемую автоматизацию. Он нужен, когда одного обзора файла уже мало.

## Когда нужен

Применяйте навык для глубокого аудита правил, поиска конфликтов и лишнего
контекста, проверки согласованности нескольких источников и разбора границы
между человеческой документацией и машиночитаемыми правилами. Для аудита только
`AGENTS.md` есть более узкий [`ai-audit-agents-md`](../ai-audit-agents-md/README.md).

## Как работает

Навык строит контур всех действующих правил, проверяет их применимость,
иерархию и конфликтность. Публичные скрипты оцениваются по наблюдаемому
поведению на значимых входах, а не по наличию файла или успешному коду выхода.
Если аудит ведёт к существенной правке, дальнейшее изменение направляется через
[`ai-work-control`](../ai-work-control/README.md).

## Что получится

Итог — приоритизированный отчёт с фактами, рисками, точками исправления и
остаточными ограничениями. Навык не объявляет README прямой инструкцией для
агента без явного обращения к нему и не исправляет проект молча.
