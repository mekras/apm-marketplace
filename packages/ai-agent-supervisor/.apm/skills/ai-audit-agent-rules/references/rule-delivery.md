# Доставка правил в контекст

Актуально на 2026-09-18. Справка охватывает только механизмы, подтверждённые
для перечисленных оснасток. Она неполна: незнакомый механизм не делает файл
человеческим контекстом и требует статуса «неопределённый».

## Как применять

Для каждой записи проверь оба условия: файл находится в форме и месте, которые
оснастка читает, и в репозитории есть наблюдение, что эта оснастка подключена к
проверяемой работе. Не выводи доставку только из имени файла. Наблюдением могут
быть настройки оснастки, манифест поставки, каталог развёрнутых правил, запись
установки или воспроизводимое поведение. Сохрани ссылку на конкретный файл и
место наблюдения.

## Codex: проектные инструкции

`AGENTS.md` является действующей инструкцией, если файл лежит на цепочке от
корня проекта до рабочего каталога задачи либо указан как резервное имя в
настройках обнаружения. Наблюдение: путь файла на этой цепочке или значение
соответствующей настройки. Учитывай ближайший файл и ограничение размера
контекста. Основание: документированные правила Codex для проектных
инструкций.

## VS Code: рабочие инструкции

Рабочая инструкция является действующей, если она размещена в поддерживаемом
для VS Code месте и в репозитории подтверждено использование этой оснастки либо
её конфигурация. Наблюдение: файл инструкции вместе с настройкой рабочей
области, расширением, манифестом или воспроизводимым сеансом, который её
подключает. Для правила с областью отдельно проверь соответствие области
назначению текста. Основание: документированные правила VS Code для рабочих
инструкций и их области.

## APM: инструкции и навыки

Поставляемая инструкция или навык является действующей инструкцией, если
манифест и реестр развёртывания подтверждают его публикацию для используемой
цели, а оснастка делает этот примитив доступным агенту. Наблюдение: исходный
примитив, запись манифеста или блокировки и соответствующий развёрнутый файл
либо список доступных навыков. Для инструкции без области проверь постоянную
доставку, для инструкции с областью — условную доставку по путям. Навык
загружается по требованию, поэтому его правила действуют только после
подтверждённого выбора навыка. Основание: документированное назначение поля
области APM.

## Неизвестный механизм и обратный поток

Если наблюдение показывает незнакомый механизм, не делай содержательную
находку по тексту кандидата. Создай находку «неопределённый статус», назови
наблюдение и спроси владельца, предназначен ли файл для агента и как он
попадает в контекст. После подтверждения задокументируй механизм и его границы
в проекте, затем добавь проверяемую запись в эту справку следующей ревизией.
Рост таких находок в отчётах — косвенный признак устаревания справки.
