# Анализ реального применения ИИ

Навык разбирает локальные сессии работы с ИИ и навыками: результаты, ошибки,
отказы, неизвестные исходы, вмешательства человека и доступные сведения
о затратах. Наблюдения накапливаются между запусками и помогают проверять
последствия согласованных улучшений.

По умолчанию анализируется текущий проект без предварительного согласования
области. Явно названный проект заменяет эту область. По явному глобальному
запросу навык охватывает все доступные локальные сессии.

## Примеры запросов

```text
Проанализируй применение ИИ в этом проекте.
```

```text
Разбери использование навыков в проекте «Мой продукт».
```

```text
Проанализируй все доступные локальные сессии по всем проектам.
```

## Результат

Отчёт показывает охват, новые и изменённые наблюдения, повторяющиеся проблемы,
ограничения и одно следующее предложение, если для него есть основание.
Причинный вклад коллекции не выводится только из успешного результата задачи.

При повторном запуске с сохранённым состоянием учитываются новые сессии и
дополнения к ранее разобранным. Старые ошибки и неизвестные исходы не теряются.
Большая история обрабатывается порциями с видимой очередью оставшихся записей.

## Ограничения

Доступность означает и технический доступ, и соблюдение действующих ограничений.
Недоступные материалы отмечаются как пробел охвата. При отсутствии истории
навык не может восстановить её из коммитов или собственного предположения.

Локальное приватное состояние содержит минимум сведений для продолжения,
без копий исходных журналов. Глобальные данные не сохраняются в текущий проект.
Если безопасное разрешённое место не определено, навык уточняет только место
хранения либо выдаёт отчёт без сохранения с явным ограничением продолжения.

Навык не запускает фоновый сбор, не создаёт расписание, не исправляет проекты
и не публикует результаты. Эти действия требуют отдельного поручения.

Для порученного улучшения навыков собранные наблюдения передаются в
`ai-skill-development`. Обучение использует то же приватное состояние,
сохраняя связь с последующими результатами. Запрос только на анализ
продолжает давать отчёт без изменения навыков.
