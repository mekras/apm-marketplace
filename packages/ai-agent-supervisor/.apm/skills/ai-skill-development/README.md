# Разработка навыков агентов

`ai-skill-development` помогает создать, изменить или проверить навык агента.
Он удерживает назначение, границы, переносимость, автоматизацию и проверки в
одном жизненном цикле, чтобы навык был полезен в реальной задаче, а не только
хорошо выглядел в файле.

## Когда нужен

Выбирайте навык для нового повторяемого процесса, переработки `SKILL.md`,
описания маршрутизации, справок, шаблонов, скриптов и оценок. Для локального
правила конкретного проекта навык сначала проверит, не дешевле ли оформить его
в инструкциях проекта.

## Какую проверку выбрать

| Задача | Навык |
| --- | --- |
| Проверить назначение, содержание, границы и качество навыка | Разработка навыков (`ai-skill-development`) |
| Проверить взаимодействие с другими правилами, конфликты и приоритеты | [Аудит правил](../ai-audit-agent-rules/README.md) |
| Проверить пакет, проекции, установку и выпуск | [Настройка APM](../ai-setup-apm/README.md) |

Для запроса «Подготовь навык к публикации» начинайте с разработки навыков.
При публикации через APM обязательные проверки APM сохраняются. Аудит правил
подключайте при конкретном риске взаимодействия, например противоречии навыка
правилам проекта. Публикация сама по себе не требует аудита всей системы.
Для запроса только о пакете сразу выбирайте настройку APM.

## Как работает

Навык выясняет, какую ошибку предотвращает процедура и на каком основании,
определяет триггеры и границы, проверяет публичную границу и выбирает нужный
масштаб правки. Повторяемая механика выносится в скрипт только при доказанной
пользе, а маршрут и результат подтверждаются сценариями. Существенная работа
начинается после [`ai-work-control`](../ai-work-control/README.md).

Всё, что навык предписывает говорить человеку, — итог, вопрос, отчёт, шаблон
документа — сверяется с [навыком общения](../ai-human-communication/README.md).
Так навык с самого начала даёт понятные ответы и не требует их переделки
по просьбе. Если меняются правила навыка, на который ссылаются другие навыки,
ссылающиеся навыки сверяются с новой редакцией.

## Что получится

Результат начинается с практического итога: что изменилось в навыке и готов ли
он к применению. Основания, проверки и оставшиеся ограничения сохраняются в
следе работы, а в ответ попадают те, что нужны для решения. Навык не превращает
переносимую процедуру в копию локального `AGENTS.md` и не делает внешнюю среду
скрытым требованием.

## Обучение

Обучение помогает улучшать навыки по опыту выполненных задач: повторяющимся
удачным способам работы, исправленным ошибкам, вашим поправкам и недостающим
правилам. По умолчанию разбор запускается вручную.

Для обучения по текущей задаче попросите:

> Используй опыт этой задачи для улучшения навыков.

Навык рассмотрит создание, разделение, объединение и перенос правил между
навыками, сравнит качество и расход контекста. Можно разрешить определённые
изменения заранее. Разбор истории сам по себе такого разрешения не даёт.

Чтобы включить автоматический разбор для следующих задач в проекте, попросите:

> Настрой автоматическое обучение в этом проекте, изменения пока только предлагай.

Во включённом режиме текущий агент перед итоговым ответом проверяет опыт
завершённой задачи. Если находит полезный новый опыт, он готовит предложение.
Режим не требует отдельной программы, фоновой работы или смены среды и способа
запуска агента. Включение разбора не даёт права менять навыки без отдельного
разрешения.

Необязательный фильтр отсеивает повторные и неподходящие наблюдения без вызова
модели. Ручной разбор доступен без Python.

Чтобы выключить автоматический разбор, попросите:

> Выключи автоматическое обучение в этом проекте.
