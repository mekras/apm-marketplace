# Сбор данных для проектного решения

`ai-data-collection` организует сбор недостающих оснований перед проектным
изменением. Он помогает не принимать единичное наблюдение, догадку или
противоречивый фрагмент за достаточный факт.

## Когда нужен

Применяйте навык, если не хватает проверяемых данных для изменения правил,
навыков, процессов или документации, источники противоречат друг другу либо
неизвестна предметная область. Для контроля уже обеспеченной задачи используйте
[`ai-work-control`](../ai-work-control/README.md).

## Как работает

Навык формулирует вопрос и решение, для которого нужны данные, описывает
неизвестное, источники, способ проверки и границы сбора. Затем он сопоставляет
собранные сведения, отмечает происхождение и отделяет подтверждённое от
гипотез. Сбор заканчивается, когда данных достаточно для названного решения,
а не когда найдено удобное подтверждение.

## Что получится

Результат содержит план или журнал сбора, проверяемые выводы, пробелы,
противоречия и следующий маршрут. Навык не принимает решение за владельца и не
подменяет анализ массива материалов.
