# Настройка и проверка APM

`ai-setup-apm` помогает подключить коллекцию навыков к проекту-потребителю или
подготовить её к публикации через APM. Он различает эти два сценария и защищает
исходники, развёрнутые проекции и файл блокировки от дрейфа.

## Когда нужен

Выбирайте навык для первоначальной настройки APM, диагностики установки,
восстановления после дрейфа, подготовки публикуемой коллекции и проверки её
границы с Git. Для изменения содержания навыка используйте
[`ai-skill-development`](../ai-skill-development/README.md).

## Как работает

Навык определяет роль проекта, проверяет манифест и доступные цели, затем
проводит самый узкий достаточный цикл установки и аудита. Перед операциями он
проверяет чистоту защищённых деревьев и после них повторяет барьер. Основной
маршрут не требует автоматизации, а необязательные средства проверяются только
после оценки среды.

## Что получится

Результат содержит статус настройки, найденные расхождения, безопасный путь их
устранения и выполненные проверки. Навык не заменяет ручной правкой файл
блокировки и не считает README заменой `apm.yml`.
