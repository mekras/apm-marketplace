# Настройка и проверка APM

`ai-setup-apm` помогает подключить коллекцию навыков к проекту-потребителю или
подготовить её к публикации через APM. Он различает эти два сценария и защищает
исходники, развёрнутые проекции и файл блокировки от дрейфа.

## Когда нужен

Выбирайте навык для первоначальной настройки APM, диагностики установки,
восстановления после дрейфа, подготовки публикуемой коллекции и проверки её
границы с Git. Для обновления зависимостей используйте
[ai-apm-update](../ai-apm-update/README.md). Для изменения и проверки содержания навыка используйте
[руководство разработки навыков](../ai-skill-development/README.md#какую-проверку-выбрать).

## Как работает

Навык определяет роль проекта, проверяет манифест и доступные цели, затем
проводит самый узкий достаточный цикл установки и аудита. Перед операциями он
проверяет чистоту защищённых деревьев и после них повторяет барьер. Основной
маршрут не требует автоматизации, а необязательные средства проверяются только
после оценки среды.

## Что получится

Вы узнаете, настроен ли проект, какие расхождения найдены и как их безопасно
устранить, а также что осталось непроверенным. Навык не заменяет ручной правкой
файл блокировки и не считает README заменой `apm.yml`.

Если проект работает в Claude Code или Hermes Agent, навык проверяет,
не попадают ли в контекст агента правила разработки установленных пакетов.
В Claude Code найденный путь он закрывает настройками самого проекта,
не дожидаясь исправления пакетов. В Hermes такой настройки нет, поэтому навык
предлагает временное правило проекта.
