# История проверки поддержки

Этот файл сохраняет в устанавливаемом пакете проверяемую границу исторической
записи журнала изменений, на которую ссылается реестр поддержки.

## Коллекция 2.6.3 — 2026-09-18

- Поставка для цели `hermes` проверена через APM CLI 0.31.0.
- Успешный результат относится к изолированному циклу блокировки зависимостей,
  установки и упаковки коллекции.
- Hermes Agent в испытании не запускался и в нём не участвовал. Загрузка и
  доступность навыков внутри Hermes не проверялись.
- Отдельный отчёт испытания в устанавливаемом пакете не сохранён.

## Коллекция 2.6.12 — 2026-09-28

- В Linux/Docker выполнена единственная успешная проверка Codex CLI 0.155.1
  с внешней изоляцией Docker и отключённой встроенной песочницей Codex.
- В испытании запрошены модель и усилие, но фактические значения не
  подтверждены. Авторизация позволила выполнить этот запуск, обновление токенов
  и длительная работа не проверялись. Задача ограничивалась правкой требования
  к итоговому ответу в `AGENTS.md`. Изменён только этот файл, исходный проект
  сохранён.
- Наблюдались чтение установленного `ai-agents-md-maintenance`, чтение его
  справок, проверка контура инструкций и итогового diff. События журнала и
  обезличенные выдержки сохранены в `evals/compatibility/evidence/`.
- Полное соблюдение всех инструкций навыка не оценивалось. Доставка
  телеметрии не подтверждена. Наблюдались ошибки обновления списка моделей и
  ошибка Git в проекте без `.git`.

## Hermes Agent 0.21.3 и локальный кандидат — 2026-09-29

- Первый прогон Hermes выполнялся с включённой защитой
  `security.protected_instruction_files`. Вызов `patch` для `AGENTS.md` ожидал
  отдельного подтверждения защищённой записи и завершился общим тайм-аутом
  после 181,315 секунды. Это не было успешным изменением файла.
- Повторный прогон выполнялся в других условиях: использован локальный кандидат
  `2.6.12-hermes-local.20260929` из commit
  `4a18241910e49d9c9bdecc77c987f4c18b5d1043`, Hermes Agent 0.21.3 и отдельный
  стендовый `HERMES_HOME` с `security.protected_instruction_files=false`.
  Общий auto-approve и yolo не включались.
- Успешный прогон подтвердил установленную через APM загрузку
  `ai-agents-md-maintenance`, точечную правку `AGENTS.md`, сохранность остальных
  файлов и исходного проекта. Наблюдались чтение навыка и его references,
  правка и проверка результата. Полное соблюдение навыка и телеметрия не
  проверялись.
- Команда Hermes, клиентский журнал и сохранённая сессия фиксируют переданные
  `gpt-5.6-luna` и `high` через `--reasoning`. Это не является независимым
  подтверждением фактических параметров на стороне сервера.
- Обезличенные исходный файл, diff и выдержки событий сохранены в
  `evals/compatibility/evidence/hermes-agent-2026-09-29/`.

## Материалы после испытания Hermes

- Справочные инструкции для Hermes, добавленные после испытания 2026-09-29,
  ещё не проходили отдельного модельного прогона.
- Испытание не расширяется задним числом: оно подтверждает только загрузку
  установленного локального кандидата и один сценарий точечной правки

- В одном подготовленном учебном проекте Hermes сам вызвал Codex для
  ограниченной подзадачи и сохранил записи запуска.
- Родитель проверил ответ, выполнил запись и проверку приёмки. Независимая
  проверка записи также прошла. Все три сервиса и оба противоречия отражены
  в ответе, исходные учебные файлы не изменены.
- Использован локальный кандидат поверх 2.6.13 с новой командой приёмки.
  Назначение родителя зафиксировано командой запуска, параметры подагента
  подтверждены на уровне клиента. Серверные параметры не проверены.

  внутри контейнера, подагент — с песочницей `read-only`.
- Установка и настройка с нуля, другие задачи, опубликованная версия и
  экономия этим прогоном не подтверждены. Предыдущие записи сохраняют свои
  исторические границы.
- Обезличенные входы, ответ, события и отчёт сохранены в
  `evals/compatibility/evidence/hermes-codex-2026-10-02/` исходного репозитория.
