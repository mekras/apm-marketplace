# Полезные решения из других проектов

Сохраняйте список локальных проектов, чьи правила, навыки и другие решения
могут пригодиться вашему продукту. По запросу вы получите предложения
с источниками, обоснованием пользы и необходимой адаптацией.

## Настройте источники

Откройте целевой проект в агенте и укажите локальные пути:

```text
Настрой сбор полезных решений из других проектов через ai-solution-discovery.
Добавь ../example-source. В нём интересны навыки подготовки документации.
```

Список сохранится в `ai-solution-sources.local.json` в корне целевого проекта.
Файл исключается из VCS. Если исключение нельзя подтвердить, сохранение
потребует сначала разрешить эту проблему. Можно указать другой файл настроек.

Чтобы изменить список, попросите добавить или удалить источник, либо уточнить
особенности проекта. Остальные записи сохранятся.

## Соберите предложения

Когда захотите проверить новые решения, попросите:

```text
Собери полезные решения из отслеживаемых проектов для текущего продукта.
```

Предложения учитывают концепцию вашего продукта и уже имеющиеся решения.
Для каждого доступны источник, конкретное изменение, ожидаемая польза,
затраты на усложнение и способ проверить эффект. Вы выбираете, что внедрять.

Анализ сопоставляет также все источники между собой: учитывает повторяющиеся
подходы, различия и условия применения. Существенные результаты сравнения
входят в обоснования соответствующих предложений. Несколько копий
организационного шаблона не доказывают, что он подходит всем пользователям.
Неизвестное происхождение совпадений будет обозначено.

В выбранных каталогах обнаруживаются вложенные проекты, в том числе без
отдельной VCS. Их собственные правила рассматриваются в контексте родителя.
Копии зависимостей и пересекающиеся пути не увеличивают число свидетельств.
Известную организацию, особенности вложенности и исключения можно указать
при настройке в заметках об источнике.

При следующем запросе используется тот же список и актуальное содержимое
источников. Если подходящих новых решений нет, вы получите этот результат.
Недоступные проекты и другие пропуски будут указаны в охвате.

Сбор запускается по запросу. Для первого варианта подходят только локальные
проекты. Доступа к их файлам достаточно, дополнительные программы не нужны.
