# Приёмка результата работы ИИ

`ai-work-result-evaluation` помогает принять, отправить на доработку, отклонить
или передать человеку результат работы ИИ. Он превращает общую оценку
«выглядит хорошо» в проверяемое решение с критериями и доказательствами.

## Когда нужен

Применяйте навык перед публикацией, принятием значимого артефакта или его
использованием как основания следующего шага. Он не нужен для чернового
обсуждения без последствий и не заменяет предварительный контроль задачи.

## Как работает

Навык определяет поверхность проверки, критерии, метрику и порог, сравнивает с
базовой линией при её наличии и запускает положительные и отрицательные
сценарии. Для повторяемой процедуры он сначала использует детерминированную
проверку и сохраняет наблюдаемые свидетельства выполнения.

## Что получится

Итог содержит сценарии и причины их прохождения или провала, ссылку на базовую
линию, решение `accept`, `revise`, `reject` либо `needs_human_decision` и
кандидаты в постоянный набор проверок. Если приёмка запускает новую
существенную правку, нужен [`ai-work-control`](../ai-work-control/README.md).
