# Передача задачи

`ai-session-handoff` помогает подготовить запрос для нового диалога, другого
агента или другого проекта. Запрос описывает проблему, цель и существенные
факты, сохраняет решения пользователя и особые ограничения задачи.

Попросите: «Подготовь запрос об этой проблеме для агента другого проекта»
или «Подготовь передачу этой задачи в новую сессию». Передайте получателю
готовый запрос и названные материалы. Способ работы получатель определит
по правилам своего проекта и уже согласованным решениям. Подготовленные
варианты решения обозначаются как наработки. При продолжении запрос также
сохраняет необходимые сведения о состоянии работы.

Фактическое продолжение и экономия оцениваются по отдельному поручению.
Подготовленный пакет сам по себе их не подтверждает.
Навык применим и при работе одним агентом.

Запрос можно проверить вручную. При наличии Python 3.10+ доступна
необязательная команда `session-handoff check --input <пакет>` для проверки
структуры: нужны разделы «Проблема и цель» и «Существенные факты», остальные
добавляются по содержанию. Прежний формат из девяти разделов поддерживается.
Установщик `scripts/install-session-handoff-tools` требует POSIX и копирует
средство с образцом в `tools/` указанного проекта.

При обновлении прежнюю команду `execution-policy check-handoff` замените
на `session-handoff check`. Разделы оценки последующего продолжения и экономии
добавляются только по отдельному поручению.
