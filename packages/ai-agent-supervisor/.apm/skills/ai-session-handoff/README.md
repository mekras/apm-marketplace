# Передача работы в новую сессию

`ai-session-handoff` помогает продолжить задачу в новом диалоге, сохранив
цель, решения, проверенные основания и состояние работы.

Попросите: «Подготовь передачу этой задачи в новую сессию».
Агент подготовит пакет и список необходимых артефактов. Передайте их новой
сессии. До её фактического продолжения пакет остаётся подготовленным,
а успешность передачи и экономия — неподтверждёнными.

Полная стенограмма или повторное выполнение завершённого этапа означают
неуспешную передачу. Качество результата и расходы всей задачи оцениваются
отдельно. Навык применим и при работе одним агентом.

Без Python пакет проверяется вручную. При наличии Python 3.10+ доступна
необязательная команда `session-handoff check --input <пакет>`.
Установщик `scripts/install-session-handoff-tools` требует POSIX и копирует
средство с образцом в `tools/` указанного проекта.

При обновлении прежнюю команду `execution-policy check-handoff` замените
на `session-handoff check`. Формат пакета и экономических свидетельств сохранён.
