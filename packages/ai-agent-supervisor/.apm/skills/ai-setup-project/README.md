# Настройка проекта для работы с агентами

`ai-setup-project` — корневая точка входа для подготовки проекта к работе с
агентами. Он обследует существующее состояние, предлагает понятные улучшения и
передаёт каждый подтверждённый шаг профильному навыку коллекции.

## Когда нужен

Используйте навык для первой настройки проекта или её повторной проверки:
машинных инструкций, общей политики выполнения, политики подагентов, APM и,
при необходимости, хуков.
Он не предназначен для написания README, требований или предметной документации.

## Как работает

Навык определяет корень проекта и уже имеющиеся настройки, ищет более
специализированный маршрут и составляет последовательность полезных шагов.
Перед каждым изменением объясняет его пользу и получает отдельное подтверждение.
При явно согласованной автономной области выполняет её без повторных
подтверждений, останавливаясь на новых полномочиях и существенных решениях.
Повторная настройка не предлагает сделанное заново, а профильные навыки не
дублируют друг друга.

После машинных инструкций навык проверяет общую политику выполнения и
проектное уточнение. Уже настроенную политику использует без пересоздания.
Если нужна настройка, отдельно предлагает её и после подтверждения передаёт
`ai-setup-execution-policy`. Приватное пользовательское ядро не копируется
в проект. Отказ не мешает остальным шагам и отражается в итоговом отчёте.
Этот шаг не переключает модель корневой сессии и не запускает дорогие испытания.

## Что получится

Результат фиксирует выполненные и делегированные шаги, решения пользователя,
актуальные ограничения и следующий незавершённый шаг. Навык не меняет файлы
молча и останавливается на решениях, которые принадлежат человеку.
