# Анализ моделей для подагентов

`ai-model-analysis` составляет сравнительный профиль доступных моделей
и усилий: качество, полные затраты и согласованные дополнительные параметры.
Профиль можно использовать в разных проектах при последующем выборе моделей
под задачи.

## Когда нужен

Применяйте навык, когда хотите сравнить доступные вам модели или обновить
прежние сведения. Цели проекта для анализа не требуются. Профиль содержит
проверяемые характеристики независимо от ваших целей.

## Что сравнивается

Область анализа — выбранные вами подключения: оснастки, поставщики и способы
доступа через подписку или API. По умолчанию предлагается охватить все доступные
модели и поддерживаемые усилия этих подключений. Если подключения или охват
ещё не выбраны, навык предложит варианты для согласования.

Сравнивается пара «модель + усилие» в конкретном способе доступа.
Данные берутся из документации, опубликованных исследований и накопленных
наблюдений. Для качества используются результаты испытаний, для затрат —
условия расхода выбранного доступа. Стоимость обращения через API, кредиты
и включённый лимит подписки учитываются раздельно.

Если для чтения истории нужно согласовать область, навык предложит
конкретный ограниченный вариант. Пока вы его рассматриваете, исследование
открытых материалов может продолжаться.

## Что получится

Результат — личный файл Markdown с характеристиками, условиями сравнения,
границами данных и обоснованными выводами. Измерения, заявления поставщика,
ваши наблюдения и выводы различаются. Неизвестные значения остаются явно
обозначенными после поиска подходящих измерений и условий расхода.

Частичный профиль отличается от завершённого исследования: вы увидите,
что уже разобрано, какой вопрос остался и что требуется для продолжения.
Сохранение файла само по себе не означает завершения анализа.

## Где хранится профиль

Навык сам предлагает имя и расположение файла, по умолчанию в корне проекта
или текущей контекстной папке. Перед первой записью вы согласуете размещение.
Файл защищается от версионирования локальными исключениями VCS. При повторном
запуске профиль читается и обновляется по согласованному пути.

Для выбранных подключений предусмотрены стандартные имена. Подробности —
в [правилах размещения личных файлов](references/storage.md).

## Границы анализа

Выбор моделей под задачи и настройка политики выполняются отдельно через
[настройку подагентов (`ai-setup-subagents`)](../ai-setup-subagents/README.md).
Анализ не меняет настройки среды и подключения.

Новые модельные испытания, включая пробные вызовы, требуют отдельного
разрешения. Перед решением вы увидите вопрос испытания, модели и усилия,
передаваемые данные, число запусков и ожидаемый расход либо предлагаемый предел
при неизвестной стоимости. Согласование охвата анализа само по себе
не разрешает такие вызовы.
