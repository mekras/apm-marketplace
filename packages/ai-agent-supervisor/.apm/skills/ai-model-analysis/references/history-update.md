# Целевое уточнение профиля по истории

Этот маршрут применяй по поручению обновить профиль либо пройти всю цепочку
настройки с анализом. Готовый разбор сам по себе не разрешает менять файлы.

1. Прочитай существующие цели, профиль и результат `ai-usage-analysis`.
   Используй уже согласованные цели, доступ и пути. При изменении цели или
   существенном противоречии уточни только затронутое решение.
2. Проверь область, срез, ссылки, группировку и ограничения передачи.
   Для конкретного вывода прочитай необходимые фрагменты, если их ещё нет.
   Отчёт и его исходная сессия — одно свидетельство, не два.
3. Обновляй только характеристики затронутых пар и операций. Раздели факт
   применения, наблюдаемый результат, приёмку и полные затраты. Известная
   операция с неизвестной приёмкой не равна отсутствию данных вообще.
   Сохраняй исправления и неизвестные расходы внешнего родителя. Не переносись
   на другую модель, усилие или операцию без отдельного основания. Для связки
   сохрани фактические параметры родителя, постановку и приёмку отдельно от
   ответа ребёнка. Учитывай явную подсказку делегирования и локальные исправления
   при приёмке. Для сравнения всей связки переноси раздельные измерения каждого
   участника, смешанные этапы и отсутствующие расходы. Сумма известных частей
   остаётся нижней границей, даже если все дочерние ответы приняты.
   Неизвестный родитель ограничивает вывод о связке, но не
   удаляет известный результат исполнителя.
4. Старую формулировку, опровергнутую историей, исправь везде, где она влияет
   на вывод. Не оставляй одновременно «область неизвестна» и перечень известных
   операций без объяснения различия. Подготовленные проверки обозначай как проверки,
   даже если они запускались в настоящем проекте.
5. История из другой оснастки может подтверждать состав задач проекта,
   но не качество пары выбранного доступа. Частоту проекта не превращай
   в универсальную характеристику модели. Токены, клиентскую оценку цены
   и расход подписки сохраняй раздельно.
6. Запиши уточнение в тот же разрешённый личный файл с защитой от VCS.
   Не удаляй неизменный каталог и внешние результаты, не добавляй обязательный
   реестр источников или историю версий. Приватные ссылки остаются в передаче.
   Если пары нет в выбранном каталоге, она остаётся историческим наблюдением
   вне назначений, а не добавляется как доступная.
7. Перечитай файл и проверь согласованность затронутых выводов. Верни
   `ai-setup-subagents` известные операции, ограничения качества и затрат
   и оставшиеся вопросы. Назови результат целевым уточнением по истории,
   не новым полным анализом каталога и открытых измерений.

Обновление не назначает роли, не меняет проектную политику и не разрешает
модельные вызовы. Недостающие сведения не заполняй предполагаемыми свойствами.
