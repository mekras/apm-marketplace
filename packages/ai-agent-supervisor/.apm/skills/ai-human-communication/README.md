# Общение агента с человеком

Навык `ai-human-communication` задаёт общие правила сообщений и других текстов
для человека, включая документацию, требования и записи решений: главное
в начале, простые слова и полезную структуру. При сообщении о проблеме
предлагает решение или следующий шаг для его поиска. Сохраняет необходимые
подробности и учитывает запрошенный формат.

При завершении поручения сообщает результат, препятствие при незавершённой
работе и конкретное продолжение. Учитывает уже полученные ответы и разрешения.

Результат анализа, контроля и приёмки по умолчанию остаётся в диалоге.
Отдельный файл отчёта создаётся по явному требованию пользователя или процедуры.
Обязательные технические журналы и состояние сохраняются по своим правилам.

Перед каждым сообщением навык требует проверить текст глазами человека,
который не видел хода работы: понятные названия вместо внутренних кодов,
обычные слова вместо непояснённых терминов процедуры, без пересказа проверок
и рабочих материалов. После работы с инструментами
агент перечитывает правила проверки перед итоговым ответом.

Для постоянного применения добавьте в инструкции агента, которые ваша
оснастка загружает в каждой сессии:

> До первого сообщения человеку открой `ai-human-communication` и применяй его ко всем сообщениям, включая промежуточные, и другим создаваемым текстам для человека. Перед отправкой каждого сообщения проверяй его по разделу «Проверка текста перед передачей».

Эту настройку также предлагает [настройка
проекта](../ai-setup-project/README.md). Ссылка на процедуру другого навыка или
пакета, где упомянут этот навык, прямую строку не заменяет: при неполном чтении
большого файла требование не доходит до агента. Если прежнее правило охватывает
только итог, остановку, вопрос о продолжении или только сообщения либо не
требует проверки каждого сообщения, дополните его. Уже подходящее подключение
менять не требуется. Правила находятся в [SKILL.md](SKILL.md), их не нужно
копировать в инструкции потребителя.

При переходе с собственных копий общих правил сначала подключите выпущенную
версию пакета с обновлённым навыком. Затем удалите копии, сохранив обязанность
открывать и применять навык. Обновите ссылки реализации требований и проверки
подключения. Предметные ограничения потребителя сохраняйте в его правилах.
Готовность исходников, выпуск пакета и обновление потребителя проверяются
отдельно.
