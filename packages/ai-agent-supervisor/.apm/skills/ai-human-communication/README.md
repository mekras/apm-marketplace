# Общение агента с человеком

Навык `ai-human-communication` задаёт краткие и понятные ответы: главное
в начале, простые слова и полезную структуру. При сообщении о проблеме
предлагает решение или следующий шаг для его поиска. Сохраняет необходимые
подробности и учитывает запрошенный формат.

При завершении поручения сообщает результат, препятствие при незавершённой
работе и конкретное продолжение. Учитывает уже полученные ответы и разрешения.

Для постоянного применения добавьте в инструкции агента:

> При общении с человеком применяй `ai-human-communication`, включая промежуточные сообщения.

Эту настройку также предлагает [настройка проекта](../ai-setup-project/README.md).
Если прежнее правило охватывает только итог, остановку или вопрос о продолжении,
замените его строкой выше. Правила находятся в [SKILL.md](SKILL.md),
дополнительных справок и программ не требуется.
