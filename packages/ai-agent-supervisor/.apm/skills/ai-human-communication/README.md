# Общение агента с человеком

Навык `ai-human-communication` задаёт краткое завершение поручения: результат,
препятствие при незавершённой работе и конкретное продолжение. Учитывает уже
полученные ответы и разрешения.

Для постоянного применения добавьте в инструкции агента:

> Перед итоговым ответом, остановкой работы или вопросом о продолжении применяй `ai-human-communication`.

Эту настройку также предлагает `ai-setup-project`. Правила находятся в
[SKILL.md](SKILL.md), дополнительных справок и программ не требуется.
