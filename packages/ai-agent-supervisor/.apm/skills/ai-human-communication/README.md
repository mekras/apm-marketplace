# Общение агента с человеком

Навык `ai-human-communication` задаёт общие правила сообщений и других текстов
для человека, включая документацию, требования и записи решений: главное
в начале, простые слова и полезную структуру. При сообщении о проблеме
предлагает решение или следующий шаг для его поиска. Сохраняет необходимые
подробности и учитывает запрошенный формат.

При завершении поручения сообщает результат, препятствие при незавершённой
работе и конкретное продолжение. Учитывает уже полученные ответы и разрешения.

Результат анализа, контроля и приёмки по умолчанию остаётся в диалоге.
Отдельный файл отчёта создаётся по явному требованию пользователя или процедуры.
Обязательные технические журналы и состояние сохраняются по своим правилам.

Для постоянного применения добавьте в инструкции агента:

> До первого сообщения человеку открой `ai-human-communication` и применяй его ко всем сообщениям, включая промежуточные, и другим создаваемым текстам для человека.

Эту настройку также предлагает [настройка проекта](../ai-setup-project/README.md).
Если прежнее правило охватывает только итог, остановку, вопрос о продолжении
или только сообщения, расширьте его до полного охвата. Уже подходящее
подключение менять не требуется. Правила находятся в [SKILL.md](SKILL.md),
их не нужно копировать в инструкции потребителя.

При переходе с собственных копий общих правил сначала подключите выпущенную
версию пакета с обновлённым навыком. Затем удалите копии, сохранив обязанность
открывать и применять навык. Обновите ссылки реализации требований и проверки
подключения. Предметные ограничения потребителя сохраняйте в его правилах.
Готовность исходников, выпуск пакета и обновление потребителя проверяются
отдельно.
