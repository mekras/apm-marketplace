# Сопровождение `AGENTS.md`

`ai-agents-md-maintenance` помогает создать, изменить и упростить `AGENTS.md`
и связанные машинные инструкции. Его цель — сделать правила проекта короткими,
операционными и согласованными, чтобы агент применял их в реальной работе, а не
воспринимал как обзорную документацию.

## Когда нужен

Применяйте навык при создании `AGENTS.md`, изменении процесса или структуры
проекта, разделении корневых и вложенных инструкций, устранении конфликтов с
`CLAUDE.md` и после повторяющихся ошибок агента. Для независимой проверки уже
готовых инструкций выберите [`ai-audit-agents-md`](../ai-audit-agents-md/README.md).

## Как работает

Навык сначала восстанавливает весь контур инструкций и их области действия,
затем определяет поведение и риск, которые должна закрыть правка. Он отделяет
операционные правила от объяснений для человека, устраняет дубли и проверяет
ссылки, команды, конфликты и границы политики Git. Содержательная правка
требует предварительного контроля через [`ai-work-control`](../ai-work-control/README.md).

## Что получится

Результат — изменённые инструкции с объяснением выбора точки входа, перечнем
перенесённых правил, сохранённой или открытой политикой Git и рекомендацией по
независимному аудиту. Навык не придумывает непроверенные правила и не заменяет
README для людей.
