# Обновление зависимостей APM

`ai-apm-update` проверяет, какие версии доступны и что изменится при их
установке. До обновления агент показывает план, ограничения из `apm.yml`
и возможные несовместимости. После одобрения он применяет план, проверяет
установку и предлагает проверить, нужны ли изменения в проекте.

## Примеры запросов

- «Покажи доступные обновления зависимостей APM и возможные несовместимости».
- «Обнови зависимости APM в пределах ограничений манифеста».
- «Обнови пакет до последней опубликованной версии. Покажи, какую привязку
  в `apm.yml` потребуется изменить».
