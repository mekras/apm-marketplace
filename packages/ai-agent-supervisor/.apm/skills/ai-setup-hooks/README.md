# Настройка хуков контроля правил

`ai-setup-hooks` настраивает внешние проверки на событиях Git, записи файлов
или непрерывной интеграции. Хук нужен только там, где свойство результата можно
проверить детерминированно, а не для повторения текстового напоминания.

## Когда нужен

Применяйте навык, чтобы обследовать кандидатов на автоматический контроль,
добавить подтверждённый хук или исправить ложные срабатывания. Для создания
самого правила используйте профильный навык, а для содержательной правки
источника истины — [`ai-work-control`](../ai-work-control/README.md).

## Как работает

Навык связывает правило с наблюдаемым свойством и конкретным событием,
отбрасывает непроверяемые случаи и показывает примеры хорошего и плохого входа.
Каждый хук требует отдельного подтверждения пользователя. Логика проверки
остаётся в проекте, а хук служит тонкой воспроизводимой обёрткой.

## Что получится

Итог перечисляет обследованные события, отобранные правила, установленные хуки,
способ активации и остаточные риски. Навык не блокирует работу ненадёжной
проверкой и не зашивает правила конкретного проекта в переносимый материал.
