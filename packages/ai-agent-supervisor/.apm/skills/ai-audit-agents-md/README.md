# Аудит `AGENTS.md`

`ai-audit-agents-md` независимо проверяет один или несколько `AGENTS.md` и
соседние машинные инструкции. Он показывает, помогают ли они агенту действовать
предсказуемо, не конфликтуют ли и не расходуют ли контекст на лишний текст.

## Когда нужен

Выбирайте навык для проверки существующих инструкций, их иерархии, связи с
`CLAUDE.md`, границы с README и подготовки замечаний перед доработкой. Для
создания и изменения файлов используйте
[`ai-agents-md-maintenance`](../ai-agents-md-maintenance/README.md).

## Как работает

Навык определяет фактическую цепочку инструкций, проверяет операционность
правил, конфликты, неявные переопределения и минимальную достаточность
контекста. В отчёте наблюдения отделены от выводов и предложений, а замечания
отсортированы по важности.

## Что получится

Читатель получает не пересказ файлов, а список доказуемых проблем, их места,
нарушенные критерии и ограничения проверки. Аудит не редактирует инструкции и
не подменяет общий аудит правил проекта.
