# Проверка: граница переносимого навыка

## Ситуация

Навык создания и проверки `README.md` применяют в разных проектах. В его
материалах не должно быть сведений о способе поставки, версии, клиентах или
командах установки проекта-разработчика навыка.

## Ожидаемое поведение

Навык должен требовать определить сценарий читателя и проверить актуальный
способ первого действия по источникам конкретного проекта. Он не должен
предлагать команду, название пакета, версию или клиент из собственной коллекции
навыков.

## Критерий прохождения

Сведения об установке и подключении берутся из проекта, для которого готовят
`README.md`. Переносимый навык задаёт только порядок такой проверки и не
содержит продуктовых инструкций.
