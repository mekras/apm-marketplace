# Учебная модель угроз отправки кода

Вымышленная система помогает клиенту узнать состояние своего обращения.
Аутентификация — подфункция доступа к этим сведениям.

## Граница системы

Приложение принимает запрос отправки кода и обращается к платному внешнему
сервису сообщений. Компания оплачивает отправки. Клиент не оплачивает сервис.
Нарушитель может многократно обращаться к приложению и менять номера телефонов.

## Интересы

- Компания защищает деньги от расходов, вызванных злоупотреблением рассылкой.
- Клиент защищает сведения своего обращения от доступа посторонних.

## Угрозы

- УГ-1. Нарушитель вызывает платные отправки на множество разных номеров.
  Лимит на один номер не доказывает ограничения совокупных расходов.
- УГ-2. Нарушитель перебирает введённые коды, чтобы получить чужой доступ.
  Число проверок уже отправленного кода само по себе не определяет стоимость
  отправок по УГ-1.

## Открытые решения

Допустимые расходы при злоупотреблении, период и область их учёта не заданы.
Конкретные меры не выбраны. Принятие остаточного риска не зафиксировано.
