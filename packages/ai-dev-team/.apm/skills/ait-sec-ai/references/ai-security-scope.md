# Состав работы по ИБ ИИ

## Минимальная модель системы

Модель угроз охватывает только применимые элементы, но для каждого исключения
указывает причину:

- данные обучения, оценки и применения, их происхождение, доступ и хранение,
- запросы, системные инструкции, ответы, контекст и память,
- поиск по базе знаний, индексы, документы и результаты поиска,
- модели, поставщики, версии, настройки и интерфейсы,
- средства агента, соединители, протоколы, учётные данные и разрешения,
- журналы, телеметрию, секреты, резервные копии и расследование инцидентов,
- код, зависимости, модели, наборы данных и цепочку поставки,
- действия агента, автономность, одобрения человека и границы доверия.

Для каждого потока указывай источник, получателя, назначение, класс данных,
границу доверия, разрешённое действие, владельца и свидетельство контроля.

## Правила

Корпоративные правила задают обязательный минимум. Проектные правила применяют
его к своему контексту и могут только усиливать. Документы не получают общий
каталог идентификаторов: каждый имеет собственную цель, владельца, область,
правило, исключения, свидетельства и дату пересмотра.

Корпоративное исключение должно содержать утверждающего владельца, точную
область, обоснование риска, компенсирующие меры, срок действия и дату
пересмотра. Без этого проектное ослабление считается несоответствием, а не
исключением.

## Аудит

Проверяй отдельно:

1. статические свидетельства: правила, модель угроз, код, настройки, разрешения,
   списки поставщиков и зависимости,
2. рабочие свидетельства: тесты, журналы, результаты проверки доступа,
   наблюдения, реагирование и подтверждение человека.

Результат содержит раздельные разделы:

- несоответствия корпоративным или проектным правилам с ссылкой на правило,
- рекомендации по внешним ориентирам, не являющиеся нарушениями,
- непроверенные меры, для которых нет достаточного свидетельства.

Не закрывай находку только ссылкой на документ, сертификацию, настройку или
пройденный функциональный тест. Для закрытия нужны свидетельства внедрения и
результативности меры.
