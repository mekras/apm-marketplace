# Договор выборочных детерминированных проверок

`selective_verification.py` выбирает и выполняет обязательные проверки до того,
как агент передаст результат модели. Средство не выполняет смысловую оценку и не
закрывает итоги вершин графа.

## Объявление проекта

Целевой проект хранит объявление в JSON. Его путь передаётся явно через
`--config`. Шаблон находится в `assets/project-verification-template.json`.

| Поле | Назначение |
| --- | --- |
| `verification.impact_graph` | Путь к графу влияния проекта. |
| `verification.full_checks` | Все обязательные детерминированные проверки. |
| `verification.global_inputs` | Общие входы полного охвата. |
| `verification.full_coverage_paths` | Дополнительные пути полного охвата. |
| `areas` | Связь вершин графа с проверками. |
| `checks` | Команды, их входы, среда и средство запуска. |

Объявление, граф и версия средства сами входят в планирующие входы. Их изменение
в следующем запуске расширяет охват до полного набора. Первый запуск с уже
неизменённым объявлением может быть выборочным.

Каждая область содержит `impact_nodes` и `checks`. Каждая вершина, до которой
доходит граф, должна иметь хотя бы одну область. Иначе сценарий запускает полный
набор проверок. Полный набор содержит все объявленные проверки.

У проверки обязательны:

- `command` — массив аргументов без оболочки,
- `cwd` — рабочий каталог внутри проекта,
- `inputs` — шаблоны исходников, тестов, настроек и зависимостей проверки,
- `environment` — исчерпывающий перечень наследуемых и явно заданных переменных,
- `tool_version_command` — команда без оболочки, определяющая версию средства.

Средство запуска передаёт команде только объявленные переменные среды. В отчёте
сохраняются только их имена и хеши значений. Значения, в том числе секреты, в
отчёт и кеш не попадают.

## Граница кеша

В кеш попадает только результат с кодом завершения `0`. Ключ включает:

- идентификатор, команду и рабочий каталог проверки,
- содержимое общих и специфичных входов, включая маркер отсутствующего входа,
- хеш объявления, графа и исполняемого средства,
- объявленные переменные среды и версию средства,
- коды завершения и вывод команды определения версии.

Неуспешный результат не сохраняется. Повреждённый или неподходящий элемент кеша
игнорируется и проверка выполняется заново.

Кеш находится в `$(git rev-parse --git-path
ai-dev-team/selective-verification)` и не предназначен для добавления в Git.

## План и отчёт

При `run` средство определяет изменения относительно обязательного `--base`:

- изменение между базой и индексом,
- изменение между индексом и рабочим деревом,
- неотслеживаемые неигнорируемые файлы,
- пути до и после переименования либо копирования.

Конфликт в индексе останавливает запуск с ошибкой, поскольку рабочее дерево не
даёт проверяемого входа. Несопоставленный путь, недоступный анализ влияния,
изменение общих входов и изменение правил планирования дают режим `full`.

В отчёте каждая проверка получает один из статусов:

- `executed` — команда выполнена в текущем запуске,
- `cached` — использован успешный результат с тем же ключом,
- `not_required` — проверка не связана с затронутыми областями.

Для `executed` и `cached` отчёт содержит причину выбора, сокращённый ключ,
код завершения, длительность и ограниченный хвост стандартного вывода и ошибок.
Агент передаёт модели этот отчёт и файлы затронутых областей. Ошибка проверки
разрешает открыть дополнительные файлы, на которые указывают свидетельства. Она
не сужает область разбирательства до исходного списка.

## Полный охват

Полный охват означает запуск всех обязательных детерминированных проверок, а не
замену полного смыслового анализа механическим запуском. К его причинам относят
как минимум:

- путь не сопоставлен с графом или областью,
- изменились граф, объявление проверок, средство или правила анализа,
- изменились манифесты, lock-файлы, настройки сборки и проверок,
- изменился генератор, схема, общий интерфейс или иной объявленный общий вход,
- анализ влияния недоступен.

После полного набора агент продолжает профильные проверки графа. Успех команды
служит свидетельством, а не доказательством отсутствия смыслового влияния.
