# Навыки использования русского языка для ИИ

Коллекция переносимых навыков для агентов ИИ, которые помогают им правильно
применять русский язык.

## Навык

`ru-lang` объединяет общие, технические, строгие и разработческие правила
русского текста.

Коллекция использует [ru-text](https://github.com/talkstream/ru-text) как
базовый редакторский слой. Он проверяет типографику, грамматику,
информационный стиль, пользовательские и деловые тексты, а также характерные
признаки машинного текста. `ru-lang` дополняет его прикладными правилами для
технического русского языка и разработки ПО.

Вместе с коллекцией устанавливаются навыки `ru-text`, `ru-check` и `ru-score`.

## Установка и обновление

Основной способ использования — установка коллекции через
[Agent Package Manager](https://github.com/microsoft/apm).

Подключить реестр:

```bash
apm marketplace add mekras/apm-marketplace --ref master
```

Установить коллекцию из реестра для Codex:

```bash
apm install ai-russian-language@mekras --target codex
```

Установить коллекцию из реестра для Claude:

```bash
apm install ai-russian-language@mekras --target claude
```

Обновить уже установленную коллекцию:

```bash
apm update
```

Проверить, есть ли новые версии зависимостей:

```bash
apm outdated
```

## Наборы правил

- `основной` — обязательные правила русского текста и исправления типичного
  поведения моделей. Подключается всегда.
- `технический` — работа с терминами, сокращениями, идентификаторами, URL и
  другими техническими элементами.
- `строгий` — последовательное употребление буквы «ё», замена англицизмов,
  гибридных форм и неточных оценок результата.
- `разработка` — сообщения коммитов, пользовательский текст и комментарии в
  коде, отчёты и другие тексты разработки ПО.

Нужные наборы перечисляются в применимом `AGENTS.md`:

```markdown
ru-lang: технический, разработка
```

Основной набор подключается, даже если не указан. Если маркера `ru-lang` нет,
для обратной совместимости подключаются все наборы.

## Использование

После установки навык становится доступен агенту как обычный локальный навык.
Дальше его можно вызывать явно по имени или использовать неявное
срабатывание там, где оно поддерживается средой.

## Разработка

Детерминированный гейт без вызовов модели и сети:

```bash
apm run tests
```

Опциональный модельный прогон качества навыков:

```bash
apm run evals
```

Модельный прогон можно сузить до одного навыка или сценария:

```bash
APM_EVAL_PATH=.apm/skills/ru-lang apm run evals
APM_EVAL_PATH=.apm/skills/ru-lang APM_EVAL_CASE_ID=<id> apm run evals
```

Публикуемые навыки лежат в `.apm/skills/<name>/`.
При добавлении или изменении навыка:

1. Обновите `SKILL.md`.
2. Синхронизируйте `agents/openai.yaml`, если меняется назначение навыка.
3. Добавьте или обновите `evals/triggers.json`.
4. При заметных изменениях обновите [CHANGELOG.md](./CHANGELOG.md).
