# История изменений

Все заметные изменения в этой коллекции навыков отражаются в этом файле.

Формат основан на `Keep a Changelog`, а версии следуют `SemVer`.

## [Не выпущено]

## [2.1.5] - 2026-08-25

### Изменено

- Базовый редакторский слой
  [ru-text](https://github.com/talkstream/ru-text) обновлён с версии `2.1.0`
  до `2.4.0`.

## [2.1.4] - 2026-08-12

### Изменено

- `ru-lang` различает маркированные и нумерованные списки, сохраняет
  грамматическое единообразие пунктов и ограничивает таблицы задачами
  сопоставления и точного соответствия. В конце текста в ячейке таблицы точка
  не ставится.
- В `ru-lang` исправлены опечатка в правилах пользовательского текста,
  внутреннее нарушение запрета точки с запятой и жаргонная замена слова
  «батчем».
- В корпусе знаний добавлены канонический понятийный слой, трассируемые
  утверждения по принятому проектному решению и явный статус обработки
  локальной книги.

## [2.1.3] - 2026-08-10

### Изменено

- `ru-lang` требует содержательной лаконичности в сохраняемых русскоязычных
  результатах. Существующий текст сокращается только по запросу пользователя.

## [2.1.2] - 2026-08-10

### Изменено

- `ru-lang` теперь предотвращает свёрнутые списки и непрошеные
  противопоставления в русских текстах.

## [2.1.1] - 2026-08-10

### Изменено

- Базовый редакторский слой
  [ru-text](https://github.com/talkstream/ru-text) обновлён с версии `2.0.1`
  до `2.1.0`.
- Коллекцию теперь можно устанавливать для цели `agent-skills`.

## [2.1.0] - 2026-07-31

### Изменено

- Базовый редакторский слой
  [ru-text](https://github.com/talkstream/ru-text) обновлён с версии `1.10.0`
  до `2.0.1`. Вместе с ним теперь устанавливаются отдельные навыки `ru-check`
  и `ru-score`.
- В README описано, какую часть проверки русского текста выполняет `ru-text`.

## [2.0.1] - 2026-07-22

### Изменено

- В `ru-lang` добавлена обязательная финальная проверка точки с запятой в
  собственной русской прозе.
- Модельные проверки принимают завершённый ответ Codex, даже если после него
  процесс завершился с ошибкой.

## [2.0.0] - 2026-07-19

### Изменено

- Навыки `ru-lang` и `ru-dev` объединены в один навык `ru-lang` с наборами
  `основной`, `технический`, `строгий` и `разработка`.
- Исправления поведения модели перенесены в обязательный основной набор.
- Два строгих справочника замен объединены в один компактный файл, а частные
  формы перенесены в сценарии проверки.
- Зависимость `talkstream/ru-text` закреплена на версии `v1.10.0`.
- Модельные сценарии теперь сравнивают результат без навыка и с навыком без
  скрытого усиления запроса и повторных попыток после содержательного ответа.

### Действия при обновлении

- Замените упоминания `ru-dev` в правилах проекта на `ru-lang` с набором
  «разработка».

## [1.2.9] - 2026-07-13

### Изменено

- Уточнены базовые правила `ru-lang`: точка с запятой используется только
  когда она нужна для ясного разделения частей фразы.

## [1.2.8] - 2026-07-03

### Изменено

- Обновлена зависимость `talkstream/ru-text` с `1.8.0` до `1.10.0`.

## [1.2.7] - 2026-07-01

### Изменено

- Добавлены правила для диагностических отчётов в `ru-lang`: риторические
  отрицания переписываются в утвердительную структуру с явным ограничением
  проверки.

## [1.2.6] - 2026-06-29

### Изменено

- Переработаны правила `ru-lang` для технического русского текста: общий
  порядок проверки теперь меньше опирается на частные перечисления и лучше
  покрывает смешанные технические формулировки.
- Добавлено правило `ru-lang` для согласования рода у иностранных сокращений
  по опорному русскому слову, включая случай `VPN`.
- Усилены правила `ru-dev` для русскоязычных пользовательских строк в коде и
  добавлены постоянные сценарии результата для CLI, UI и сообщений об ошибках.

## [1.2.5] - 2026-06-22

### Изменено

- Уточнены правила `ru-lang` для обычных ответов, рецензий и пересказов, а
  также для англицизмов, записанных кириллицей.
- Уточнены правила `ru-dev` для сообщений коммита, включая форму результата и
  запрет строк соавторства в сообщении.

## [1.2.4] - 2026-06-20

### Изменено

- Дополнен словарь и правила `ru-lang`: запрещены `эвал` и `бандл` во всех
  формах, ограничено злоупотребление словом `конвенция`.
- Разделены проверки коллекции: `apm run tests` стал детерминированным гейтом
  без вызовов модели, а модельный прогон вынесен в отдельную команду
  `apm run evals`.

## [1.2.3] - 2026-06-19

### Изменено

- Дополнены словарь и правила `ru-lang` для англицизмов, записанных кириллицей.
- Уточнены проверки и примеры для словаря `ru-lang`.

## [1.2.2] - 2026-06-19

### Изменено

- Оптимизирован `ru-dev`: подробные правила вынесены в отдельную справку,
  а основной файл стал короче и легче для маршрутизации.
- Уплотнён словарь `ru-lang` для слова `деплой` и его форм.

### Исправлено

- Обновлены проверки срабатывания и сценарии результата для `ru-dev` и
  `ru-lang`.
- Исправлен запуск `tools/codex-model-subagent` под текущие значения
  `approvals_reviewer` в Codex CLI.

## [1.2.1] - 2026-06-18

### Изменено

- Упрощён `ru-lang`: длинный список замен вынесен в справочники, а старые
  дублирующие файлы удалены из публикуемого состава.

### Исправлено

- Обновлён `apm.lock.yaml` после удаления устаревших файлов и повторной
  установки локального состава.

## [1.2.0] - 2026-06-18

### Изменено

- Исходники навыков перенесены в `.apm/skills/`, а `apm run tests` переведён
  на структурные проверки и выборочный запуск через `APM_EVAL_PATH` и

### Исправлено

- Стабилизированы сценарии результата `ru-lang` для гибридных форм с DNS,

## [1.1.2] - 2026-06-18
